# Documentation Directory Instructions

This directory contains persistent framework documentation.

## Intended Content

Examples:

- architecture explanations
- project registry
- framework conventions
- DB conventions
- API conventions
- lifecycle documentation
- decision records
- operational guides
- change logs

## Rules

Documentation must reflect accepted framework state.

Do not store temporary Agent execution state here.

Do not store temporary task logs here.

Do not use docs as a substitute for runtime/.

Architecture descriptions must remain consistent with:

`../diagrams/multi_agent_framework_v3_workspace.drawio`

When the diagram changes, identify documentation that may need updating.

Do not rewrite unrelated documentation during a small task.
